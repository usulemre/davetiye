# Muhammed İsmet & Tuğçe · Davetiye

React + Vite ile hazırlanmış dijital davetiye.

## Bilgileri düzenleme
Tarih, IBAN, program ve mekân bilgilerinin hepsi `src/config.js` dosyasında.

## Yerelde çalıştırma
```bash
npm install
npm run dev
```

## Yayına alma (GitHub + Vercel)
1. Projeyi GitHub'a yükleyin.
2. vercel.com → **Add New → Project** → repoyu seçin.
3. Framework olarak **Vite** otomatik seçilir → **Deploy**.
